# 放映、演講者檢視與匯出

簡報是一個普通網頁：開發時用 `npx pcafe dev <name>` 在瀏覽器裡開啟，交付時用 `npx pcafe build <name>` 產生 `dist/<name>.html`。這個檔案是單個離線檔案，字型、圖片、腳本都已內聯，可以直接發給別人用瀏覽器開啟，不需要連網。

## 快捷鍵

| 操作 | 按鍵 |
| --- | --- |
| 下一頁 / 上一頁 | `→` `←`，`Space`，`PageDown` `PageUp` |
| 第一頁 / 最後一頁 | `Home` / `End` |
| 全屏 | `F`，或控制欄右側按鈕 |
| 總覽全部頁面 | `G`；方向鍵選擇，`Enter` 開啟，`Esc` 返回 |
| 自動播放 | `P` 開始 / 暫停，每 8 秒前進一步（含逐條展開），到最後一頁自動停；開啟總覽、黑屏或凍結時暫停計時 |
| 演講者檢視 | `S` 開啟新視窗 |
| 雷射筆 | `L` 開 / 關，`Esc` 關 |
| 畫筆 | `D` 開 / 關，`C` 清除；翻頁自動清除 |
| 區域性放大 | `Z` 後點一下放大 2 倍；再按 `Z`、`Esc` 或翻頁恢復 |
| 黑屏 / 白屏 | `B` 黑屏，`W` 白屏；再按同一個鍵恢復 |
| 凍結觀眾畫面 | `H` 讓觀眾停在目前畫面；再按 `H` 解除，畫面跟到你現在的位置 |
| 快捷鍵說明 | `?`；再按 `?` 或 `Esc` 關閉 |
| 跳到某頁 | 點選底部進度條，或開啟 `#/N`（例如 `#/5`） |
| Bento 展開 / 返回 | 點選卡片或按 `Tab` `Enter` / `Esc` |

**控制欄**：移動滑鼠時出現在右下角，有上一步、播放、下一步、總覽、全屏幾個按鈕；滑鼠靜止 2.4 秒後隱藏，截圖和投影時不會露出來。

**黑屏、白屏與凍結**：`B` 讓觀眾螢幕變黑，`W` 變白，再按同一個鍵恢復。`H` 凍結觀眾看到的畫面：你可以繼續翻頁、逐條展開，觀眾螢幕不動；再按 `H`，畫面直接跳到你目前所在的頁和步驟。這三種狀態下翻頁都照常進行，所以可以先黑屏、翻到下一頁，再亮屏揭曉。放映視窗和演講者窗口裡都能按。

**逐條展開**：設了 `build` 的頁，用 `→` / `Space` 進入後每按一次出現一項；頁首右側的小圓點顯示進度，全部出現後再按才翻頁；`←` 逐項收回。用進度條、總覽或 `#/N` 跳過來時直接顯示全部內容。寫法見 [guide.md 第 14 節](guide.md#build)。

## 演講者檢視

按 `S`，或直接開啟 `#/presenter`。新窗口裡有目前頁、下一頁、備註、排練計時和時鐘。在任一視窗翻頁，另一個視窗會同步。常見用法是把演講者視窗留在筆記本螢幕上，把放映視窗拖到投影上按 `F` 全屏。按 `?` 檢視這個窗口裡能用的按鍵。

- **觀眾螢幕**：目前頁下方的「黑屏」「白屏」「凍結畫面」按鈕（或 `B`、`W`、`H`）控制觀眾螢幕。黑屏或白屏時，演講者視圖裡的目前頁會蓋上「觀眾螢幕已黑屏 / 已白屏」的提示；凍結時，頂部一條提示寫明觀眾還停在哪一頁。
- **連線狀態**：頂欄顯示放映視窗是否已連線。放映視窗被關掉，或幾秒內沒有回應，就顯示「放映視窗未連線」，旁邊有「重新開啟放映視窗」按鈕，會在目前頁重新開啟。凍結狀態下關掉演講者視窗，放映視窗稍後會自動解除凍結，讓觀眾看到目前頁；黑屏、白屏會保留，到放映視窗按 `B` / `W` 恢復。
- **排練計時**：放映視窗連上後自動開始計時，「暫停計時 / 繼續計時」和「重置計時」都是按鈕。時間記在當時顯示的那一頁上，所以能看到總用時和本頁用時；「每頁用時」把備註區換成每一頁的用時表。結果儲存在瀏覽器的 localStorage 裡，重新整理後還在，這時不會自動開始，等你點「繼續計時」或「重置計時」；瀏覽器禁止儲存時計時照常工作，只是下次從零開始。

備註和計畫時間寫在每頁上：

```tsx
{ id: 'numbers', label: '規模', notes: '先停 3 秒，讓大家看清數字。', seconds: 90, render: () => <StatRow … /> }
```

`seconds` 可選，是這一頁計畫講多少秒。寫了以後，演講者檢視會對比本頁和全場的計畫用時與實際用時（計畫總時長是所有寫了 `seconds` 的頁相加），超時的部分用主題色標出。`npx pcafe check` 會輸出一行 `note:`，說明多少頁有備註、計畫總時長多少；沒寫備註不算失敗。

## 匯出 PDF

開啟 `#/print`，點「列印 / 存為 PDF」，在瀏覽器的列印對話方塊裡選「存為 PDF」。每頁一張投影片，逐條展開的內容全部顯示。毛玻璃模糊和漸變字在 PDF 裡會簡化。

**閱讀版**：開啟 `#/read`，整份簡報變成一頁可以滾動的網頁：每頁按視窗寬度縮放，章節按 `SectionBreak` 自動分組，左邊是章節目錄，每頁下面顯示演講備註。適合會後把連結發給別人，手機上也能看。

## 匯出 PowerPoint

```bash
npx pcafe pptx <簡報名>
```

產生 `dist/<簡報名>.pptx`（16:9，13.333 × 7.5 英寸）和一份報告 `dist/<簡報名>.pptx.json`。`dist/<簡報名>.html` 不存在或比 `src/` 舊時會先建置；加 `--build` 強制重新建置。

做法：在 Chromium 裡按 `#/print` 的樣子開啟每一頁，逐條展開的內容全部顯示，動畫停在終點，數字停在最終值。普通的橫排文字變成 PowerPoint 原生文字方塊，每行一個，位置和字號跟瀏覽器裡一樣。頁面其餘部分截成一張圖，作為這一頁的背景。截圖時只把做成文字方塊的那些字隱去，所以同一段字不會出現兩次。能幹淨分離的照片（`<img>`）單獨做成圖片。演講備註（`notes`）寫進 PowerPoint 的備註。

限制：

- 背景圖不能編輯。形狀、卡片、線條、圖示、背景紋理和圖表都是畫素，要改就改簡報，再匯出一次。
- PowerPoint 畫不出同樣效果的文字留在背景圖裡，不能編輯：圖表和 SVG 裡的標籤、漸變字或裁切字、旋轉或變形的文字、帶陰影/描邊/遮罩/下劃線的文字、被部分遮住的文字，以及 CSS 產生的文字（`::before`、`::after`）。emoji 也留在背景圖裡，它前後的文字會分成兩個文字方塊。報告逐頁列出這些文字和原因。
- 每行是一個單獨的文字方塊，不會自動換行。改寫句子時要自己調整或合併文字方塊。
- 字型只寫名字，不嵌入。觀看者電腦上沒有的字型，PowerPoint 會換成別的，文字可能比 HTML 裡寬或窄。西文用 Geist、Geist Mono、Instrument Serif（以及 `style` 對應的標題字型），中文用 Noto Sans SC 和 Noto Serif SC，裝上這些字型效果最接近（Linux 上的 Noto Sans CJK SC 是同一套字形，只是名字不同）。HTML 裡等寬排列的數字在 PowerPoint 裡按字型的普通寬度排；特別大的展示數字上下位置可能略有偏差。
- LibreOffice 會自己在中文和西文之間加空隙，PowerPoint 不會。

匯出時會自查：如果有文字既在文字方塊裡又留在背景圖裡，指令會指出是哪一段並報錯退出。完整檢查用 `node scripts/pptx-selftest.mjs <簡報名>`。

## 紋理與翻頁方式

這兩個是整份簡報的選項，寫在 `DeckDef` 上：

```tsx
export const deck: DeckDef = {
  title: '…',
  texture: 'grain',      // none（預設）/ grain / paper / noise-dark，整頁淡淡的紋理
  transition: 'slide',   // fade（預設）/ slide / zoom / wipe / none
  backdrop: 'dots',      // none（預設）/ dots / mesh / paper / particles / grid，內容後面的背景層
  slides: [ … ],
}
```

`backdrop` 是墊在內容下面的裝飾背景：`dots` 點陣、`mesh` 慢速流動的色塊漸變、`paper` 紙張顆粒、`particles` 粒子、`grid` 緩慢縮放的方格。顏色跟隨主題和深色頁；動畫很慢，開啟「減少動態效果」或列印時靜止。單頁可以用 `SlideDef.backdrop` 覆蓋，寫 `'none'` 關掉（例如整頁照片）。

目錄裡的章節編號會飛到下一頁章節頁的大號數字上，這是 `Agenda` 和 `SectionBreak` 自帶的翻頁銜接，不需要設定。
