# 放映、演讲者视图与导出

演示是一个普通网页：开发时用 `npx pcafe dev <name>` 在浏览器里打开，交付时用 `npx pcafe build <name>` 生成 `dist/<name>.html`。这个文件是单个离线文件，字体、图片、脚本都已内联，可以直接发给别人用浏览器打开，不需要联网。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 下一页 / 上一页 | `→` `←`，`Space`，`PageDown` `PageUp` |
| 第一页 / 最后一页 | `Home` / `End` |
| 全屏 | `F`，或控制栏右侧按钮 |
| 总览全部页面 | `G`；方向键选择，`Enter` 打开，`Esc` 返回 |
| 自动播放 | `P` 开始 / 暂停，每 8 秒前进一步（含逐条展开），到最后一页自动停；打开总览、黑屏或冻结时暂停计时 |
| 演讲者视图 | `S` 打开新窗口 |
| 激光笔 | `L` 开 / 关，`Esc` 关 |
| 画笔 | `D` 开 / 关，`C` 清除；翻页自动清除 |
| 局部放大 | `Z` 后点一下放大 2 倍；再按 `Z`、`Esc` 或翻页恢复 |

| 冻结观众画面 | `H` 让观众停在当前画面；再按 `H` 解除，画面跟到你现在的位置 |
| 快捷键说明 | `?`；再按 `?` 或 `Esc` 关闭 |
| 跳到某页 | 点击底部进度条，或打开 `#/N`（例如 `#/5`） |
| Bento 展开 / 返回 | 点击卡片或按 `Tab` `Enter` / `Esc` |

**控制栏**：移动鼠标时出现在右下角，有上一步、播放、下一步、总览、全屏几个按钮；鼠标静止 2.4 秒后隐藏，截图和投影时不会露出来。

**黑屏、白屏与冻结**：`B` 让观众屏幕变黑，`W` 变白，再按同一个键恢复。`H` 冻结观众看到的画面：你可以继续翻页、逐条展开，观众屏幕不动；再按 `H`，画面直接跳到你当前所在的页和步骤。这三种状态下翻页都照常进行，所以可以先黑屏、翻到下一页，再亮屏揭晓。放映窗口和演讲者窗口里都能按。

**逐条展开**：设了 `build` 的页，用 `→` / `Space` 进入后每按一次出现一项；页眉右侧的小圆点显示进度，全部出现后再按才翻页；`←` 逐项收回。用进度条、总览或 `#/N` 跳过来时直接显示全部内容。写法见 [guide.md 第 14 节](guide.md#build)。

## 演讲者视图

按 `S`，或直接打开 `#/presenter`。新窗口里有当前页、下一页、备注、排练计时和时钟。在任一窗口翻页，另一个窗口会同步。常见用法是把演讲者窗口留在笔记本屏幕上，把放映窗口拖到投影上按 `F` 全屏。按 `?` 查看这个窗口里能用的按键。

- **观众屏幕**：当前页下方的“黑屏”“白屏”“冻结画面”按钮（或 `B`、`W`、`H`）控制观众屏幕。黑屏或白屏时，演讲者视图里的当前页会盖上“观众屏幕已黑屏 / 已白屏”的提示；冻结时，顶部一条提示写明观众还停在哪一页。
- **连接状态**：顶栏显示放映窗口是否已连接。放映窗口被关掉，或几秒内没有回应，就显示“放映窗口未连接”，旁边有“重新打开放映窗口”按钮，会在当前页重新打开。冻结状态下关掉演讲者窗口，放映窗口稍后会自动解除冻结，让观众看到当前页；黑屏、白屏会保留，到放映窗口按 `B` / `W` 恢复。
- **排练计时**：放映窗口连上后自动开始计时，“暂停计时 / 继续计时”和“重置计时”都是按钮。时间记在当时显示的那一页上，所以能看到总用时和本页用时；“每页用时”把备注区换成每一页的用时表。结果保存在浏览器的 localStorage 里，刷新后还在，这时不会自动开始，等你点“继续计时”或“重置计时”；浏览器禁止存储时计时照常工作，只是下次从零开始。

备注和计划时间写在每页上：

```tsx
{ id: 'numbers', label: '规模', notes: '先停 3 秒，让大家看清数字。', seconds: 90, render: () => <StatRow … /> }
```

`seconds` 可选，是这一页计划讲多少秒。写了以后，演讲者视图会对比本页和全场的计划用时与实际用时（计划总时长是所有写了 `seconds` 的页相加），超时的部分用主题色标出。`npx pcafe check` 会输出一行 `note:`，说明多少页有备注、计划总时长多少；没写备注不算失败。

## 导出 PDF

打开 `#/print`，点“打印 / 存为 PDF”，在浏览器的打印对话框里选“存为 PDF”。每页一张幻灯片，逐条展开的内容全部显示。毛玻璃模糊和渐变字在 PDF 里会简化。

**阅读版**：打开 `#/read`，整份演示变成一页可以滚动的网页：每页按窗口宽度缩放，章节按 `SectionBreak` 自动分组，左边是章节目录，每页下面显示演讲备注。适合会后把链接发给别人，手机上也能看。

## 导出 PowerPoint

```bash
npx pcafe pptx <演示名>
```

生成 `dist/<演示名>.pptx`（16:9，13.333 × 7.5 英寸）和一份报告 `dist/<演示名>.pptx.json`。`dist/<演示名>.html` 不存在或比 `src/` 旧时会先构建；加 `--build` 强制重新构建。

做法：在 Chromium 里按 `#/print` 的样子打开每一页，逐条展开的内容全部显示，动画停在终点，数字停在最终值。普通的横排文字变成 PowerPoint 原生文本框，每行一个，位置和字号跟浏览器里一样。页面其余部分截成一张图，作为这一页的背景。截图时只把做成文本框的那些字隐去，所以同一段字不会出现两次。能干净分离的照片（`<img>`）单独做成图片。演讲备注（`notes`）写进 PowerPoint 的备注。

限制：

- 背景图不能编辑。形状、卡片、线条、图标、背景纹理和图表都是像素，要改就改演示，再导出一次。
- PowerPoint 画不出同样效果的文字留在背景图里，不能编辑：图表和 SVG 里的标签、渐变字或裁切字、旋转或变形的文字、带阴影/描边/遮罩/下划线的文字、被部分遮住的文字，以及 CSS 生成的文字（`::before`、`::after`）。emoji 也留在背景图里，它前后的文字会分成两个文本框。报告逐页列出这些文字和原因。
- 每行是一个单独的文本框，不会自动换行。改写句子时要自己调整或合并文本框。
- 字体只写名字，不嵌入。观看者电脑上没有的字体，PowerPoint 会换成别的，文字可能比 HTML 里宽或窄。西文用 Geist、Geist Mono、Instrument Serif（以及 `style` 对应的标题字体），中文用 Noto Sans SC 和 Noto Serif SC，装上这些字体效果最接近（Linux 上的 Noto Sans CJK SC 是同一套字形，只是名字不同）。HTML 里等宽排列的数字在 PowerPoint 里按字体的普通宽度排；特别大的展示数字上下位置可能略有偏差。
- LibreOffice 会自己在中文和西文之间加空隙，PowerPoint 不会。

导出时会自查：如果有文字既在文本框里又留在背景图里，命令会指出是哪一段并报错退出。完整检查用 `node scripts/pptx-selftest.mjs <演示名>`。

## 纹理与翻页方式

这两个是整份演示的选项，写在 `DeckDef` 上：

```tsx
export const deck: DeckDef = {
  title: '…',
  texture: 'grain',      // none（默认）/ grain / paper / noise-dark，整页淡淡的纹理
  transition: 'slide',   // fade（默认）/ slide / zoom / wipe / none
  backdrop: 'dots',      // none（默认）/ dots / mesh / paper / particles / grid，内容后面的背景层
  slides: [ … ],
}
```

`backdrop` 是垫在内容下面的装饰背景：`dots` 点阵、`mesh` 慢速流动的色块渐变、`paper` 纸张颗粒、`particles` 粒子、`grid` 缓慢缩放的方格。颜色跟随主题和深色页；动画很慢，开启“减少动态效果”或打印时静止。单页可以用 `SlideDef.backdrop` 覆盖，写 `'none'` 关掉（例如整页照片）。

目录里的章节编号会飞到下一页章节页的大号数字上，这是 `Agenda` 和 `SectionBreak` 自带的翻页衔接，不需要设置。
