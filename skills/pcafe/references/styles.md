# 风格与配色

> 由 `npm run docs` 从 `src/kit/catalog.ts` 和 `src/kit/theme.ts` 生成，请勿手改。

`DeckDef.style` 选一种风格，`DeckDef.theme` 选一套配色，两者可以任意组合。
