### `LineChart` Line chart (Trend - change over time)
- Use when: Change across 4–12 points in time: releases, years, quarters, months; A point in time needs a callout
- Avoid: Only 2–3 points: use MetricBars or DeltaBars; Different objects at one moment are compared: use MetricBars; Periods add and subtract into each other: use Waterfall
- Limits: x 4–12 labels, ≤ 6 characters each; series 1–3 with only one focus; write approximate values in labels as in the original, e.g. 43,000+; annotations ≤ 2, text ≤ 16 chars, never on the last point; yFrom defaults to 0; say so in the lead when the axis start is raised; notes 2–3: key ≤ 8 chars, text ≤ 30 chars
- Reference: src/decks/release slide `packages`; docs/en/components.md#line-chart; interaction: The line draws from left to right, data points pop in one by one and the annotations fade in last.
