### `BigStat` Single big number (Evidence - one number carries the slide)
- Use when: One number is the argument: 97%, 9.34%, 1/100; A visual accent is needed between a run of text slides
- Avoid: Several numbers matter equally: use MetricBars; The number only means something next to others: use DeltaBars or Dumbbell; Used more than 3 times in one deck
- Limits: figure ≤ 6 characters (unit included); the shorter it is, the larger the type; caption ≤ 30 chars; say what the number counts; support 2–3 items: value ≤ 8 characters, label ≤ 24 chars; title 2 lines × ≤ 8 chars (right column 640u wide)
- Reference: src/decks/geo slide `fanout`; docs/en/components.md#big-stat; interaction: Digits rise out of a mask one by one and drift slightly with the pointer.

### `DeltaBars` Positive and negative change (Evidence - up or down)
- Use when: Change after a test or a change: citation rate, conversion rate, time taken; The same treatment moves in different directions on different platforms
- Avoid: All values are positive totals: use MetricBars; Both the before and the after value need showing: use Dumbbell
- Limits: rows 2–6: label ≤ 10 chars, sub ≤ 14 characters; unit ≤ 4 characters; scale is the half-width of the axis, an integer slightly above the largest absolute value; ends each ≤ 6 chars, for example “fewer citations / more citations”; When the change is not significant, say so in the title or lead; do not let the bars imply an effect
- Reference: src/decks/geo slide `schema`; docs/en/components.md#delta-bars; interaction: Bars grow out from the zero line to both sides.

### `Dumbbell` Two-point comparison (Evidence - two ways to measure one metric)
- Use when: One metric under two conditions: API and App, last year and this year, control and test; The gap itself is the argument
- Avoid: Only one condition: use MetricBars; More than 5 rows: split the slide or keep only the most telling rows
- Limits: rows 2–5: label ≤ 8 chars, sub ≤ 14 characters; legend two items, each ≤ 8 chars; max defaults to 100; unit defaults to %, and the gap is written as “percentage points”; footnote ≤ 60 chars
- Reference: src/decks/geo slide `api-app`; docs/en/components.md#dumbbell; interaction: Point a appears first, the line grows from a to b, then point b pops in.
