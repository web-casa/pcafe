### `TabPanels` Tab panels (Expansion - several sides of one topic)
- Use when: A process or topic has 3–5 parallel sides and you want to cover one at a time; Each side has about the same amount of content
- Avoid: Items must be compared at once: use Matrix or CompareTable; Each tab needs a screenshot: use TabbedShot; In print and in the overview only the tab set by open shows; the other tabs stay hidden
- Limits: tabs 3–5; tab ≤ 6 chars or ≤ 12 Latin characters; title ≤ 20 chars; body ≤ 80 chars; points 0–3, each ≤ 22 chars; stat.value ≤ 8 characters, stat.label ≤ 12 chars; with stat, points is at most 2
- Reference: src/decks/v3-p1 slide `process`; docs/en/components.md#tab-panels; interaction: With build: 'focus', each press → the next tab is selected and the content changes
