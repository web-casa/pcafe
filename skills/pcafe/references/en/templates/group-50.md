### `RetroTabs` Retro tab window (Grouping - 2–4 parallel lists)
- Use when: Lists grouped by role, stage or scenario; Clicking through the tabs live, group by group
- Avoid: Only one group: use IconGrid; A screenshot shows only the first tab, so put the key content in the first group
- Limits: tabs 2–4, label ≤ 6 chars; rows 3–4 per group: title ≤ 10 chars, note ≤ 26 chars; file ≤ 20 characters; title ≤ 2 lines × 8 chars
