### `CompareTable` Before and after table (Comparison - old → new)
- Use when: Version upgrades, policy changes, before and after a redesign; Every row is the old and new value of one dimension
- Avoid: Only 1–2 changes: put them in NumberedColumns; Three or more sides to compare: split the slide or build it custom; A cell needs a line break to explain
- Limits: rows 4–7; fewer than 4 leaves the bottom empty; Every cell must fit on one line: item ≤ 12 chars, value ≤ 22 chars; Set mono: true for commands and file names
- Reference: src/decks/release slide `compare`; docs/en/components.md#compare-table

### `DuoCards` Two-color option cards (Comparison - two options or two uses)
- Use when: Two options, two tiers, two ways of using something; Each one has a number that represents it
- Avoid: Three tiers: use PricingTiers; You need a row-by-row attribute comparison: use CompareTable
- Limits: cards exactly 2: name ≤ 8 chars, value ≤ 6 characters, note ≤ 24 chars, items 3–5, each ≤ 16 chars
- Reference: src/decks/toy3d slide `outputs`; docs/en/components.md#duo-cards

### `DoubleFunnel` Double funnel comparison (Comparison - two groups going through the same stages)
- Use when: Conversion comparison of two groups or two versions; 3–5 identical stages
- Avoid: Only one group: use Funnel; Different stages: split into two slides
- Limits: stages 3–5 each ≤ 8 chars; values match stages one to one and never increase; name ≤ 8 chars
- Reference: src/decks/wallpaper slide `funnel`; docs/en/components.md#double-funnel

### `CompareSlider` Before-and-after slider (Comparison - before and after in the same view)
- Use when: Same-position comparisons: redesign, restoration, seasons; The audience should pull the curtain back to see the change
- Avoid: The two images are framed differently: use BeforeAfter or DuoCards; Comparing numbers: use a chart
- Limits: title ≤ 1 line × 16 chars; lead ≤ 40 chars; before.label / after.label ≤ 8 chars; stops 1–3: at is 0–100, note ≤ 24 chars; The two images must match in size and framing; generated images must say "illustrative" in note or credit
- Reference: src/decks/v2-p1 slide `compare`; docs/en/components.md#compare-slider; interaction: build: the divider slides step by step and the notes light up in turn

### `ParadigmCards` Model comparison cards (Comparison - structure of 2–3 approaches)
- Use when: Compare 2–3 models for organising data or doing the work; Every model is described with the same few dimensions
- Avoid: More than 4 dimensions or scores are needed: use CompareTable; The structure sketch is unrelated to the content: use PanelCards
- Limits: cards 2–3; name ≤ 8 chars; tagline ≤ 16 chars; rows 2–4: label ≤ 4 chars, value ≤ 16 chars; the label order is the same on every card; shape is only tree / blocks / flat
- Reference: src/decks/v3-p5 slide `models`; docs/en/components.md#paradigm-cards; interaction: build: reveal — each step shows one card
