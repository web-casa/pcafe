### `Typewriter` Typewriter (Quotation - one quote typed out letter by letter)
- Use when: A quote from a telegram, radio or command line; A short line the audience should read one character at a time
- Avoid: A long quotation: use Quote; The sentence does not feel like it is being typed: use Statement
- Limits: lines 1–3, each ≤ 32 Latin characters or ≤ 16 chars; caption ≤ 40 chars; meta 0–3: label ≤ 6 chars, value ≤ 12 chars

### `KaraokeLines` Script highlighter (Quotation - read a script line by line)
- Use when: A speech, oath or lyric-like passage; You want the audience to read line by line with the rhythm
- Avoid: Only one sentence: use Quote or Statement; Any line longer than 14 chars
- Limits: lines 3–6, each ≤ 14 chars; aside ≤ 120 Latin characters or ≤ 60 chars; by ≤ 24 chars
- Reference: src/decks/v2-p2 slide `speech`; docs/en/components.md#karaoke-lines; interaction: In build mode each press → light the next line; in the complete state the last line stays in the accent colour
