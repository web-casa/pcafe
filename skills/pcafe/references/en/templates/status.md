### `StatusGrid` Status grid (Status - state of each object in a set)
- Use when: Support or readiness of a set of objects: architectures, platforms, functions, modules; The audience should see at a glance how many are fine and how many are not
- Avoid: Each object must be compared on several dimensions: use Matrix; Only two states and fewer than 4 objects: use VerdictColumns
- Limits: tiles 6–10; 6 in 3 columns, 7–8 in 4, 9–10 in 5; name ≤ 10 characters (monospace); sub ≤ 12 chars; note ≤ 24 chars, only for partial or unsupported; labels ≤ 4 chars each
